# One-Line Office Joke Laugh-Off

This entry submits a single original one-liner about office life for the make.fun "One-Line Office Joke Laugh-Off" competition. The program writes the joke to the required output file when executed.

## Run it

```bash
node main.ts
```

The joke is written to `MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is not set).
